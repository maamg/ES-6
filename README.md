# Modern JavaScript Fundamentals

Small exercises covering let/const, template literals, spread syntax, default parameters, arrow functions, classes and inheritance.

**Category:** JavaScript fundamentals

[All projects](https://github.com/maamg/maamg/blob/main/PROJECTS.md) · [Programming practice](https://github.com/maamg/jhalai)

## Run an exercise

Use Node.js and run an individual file, for example:

```sh
node "arrow.js"
```

These are independent learning examples rather than a packaged application.
